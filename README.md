# Market Clock

A live global stock exchange trading hours widget — clocks for NYSE, TSX, LSE, TSE, HKEX and SGX, a shared 24-hour session map with pre/post market, lunch breaks and overlap depth, macro-release markers, and a 14-day holiday/DST closures list. Home timezone is set to Europe/London.

Static HTML/CSS/JS, no build step, installable as a PWA on iPhone (Add to Home Screen) with offline caching via a service worker.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server.
